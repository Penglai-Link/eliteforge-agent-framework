# 动态能力包验收

本页是动态能力包运行时的回归入口。设计与契约见[动态能力包运行时设计](动态能力包运行时设计.md)，破坏式 API 变更见[迁移说明](动态能力包迁移说明.md)。

| 验收点 | 可执行依据 |
| --- | --- |
| 包安装、版本、签名和路径安全 | `crates/framework/eliteforge-agent-capability-runtime` 的安装与归档测试 |
| 选择隔离、依赖解析与静态能力包 | `crates/framework/eliteforge-agent-framework/tests/capability_packs.rs` |
| 远程扩展点和双向调用 | `crates/tools/eliteforge-agent-capability-dev-host/tests/sidecar.rs` |
| 取消、关闭和子进程清理 | 能力运行时测试、开发宿主 sidecar 测试及 MCP 传输测试 |
| 页面与宿主挂载 | `sdk/page/tests/browser.mjs` |
| 本次新增模型检测和异步图片任务 | `crates/framework/eliteforge-agent-framework/tests/model_capabilities.rs` 与能力运行时契约测试 |

这些测试使用本地 mock 或 sidecar，不会验证真实供应商账号。macOS 上的通过结果不能推断 Windows、Linux 进程控制、文件权限和浏览器行为均已通过；三平台验收须以对应 CI 的实际执行结果为准。安装包不自动切换已有 Agent，失败的重配不得破坏旧实例。活跃页面、模型会话和未完成模型任务的占用规则仍由运行时执行。
