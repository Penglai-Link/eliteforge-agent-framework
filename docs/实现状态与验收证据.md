## 接手后的独立审查修复

在保留原任务改动的基础上增加 3 项回归：

- JSON Bridge 取消 HTTP 请求最多等待 5 秒；不响应的本地服务验证超时返回并释放连接。Drop 仍仅尽力取消，不表示远端停止已确认。
- 按连接更新现在同样校验 `EmbeddingSpace.model.connection`，防止提供方注入其他连接的空间配置；失败时原快照不变，本连接的退役空间仍能保留。
- PersonAI Responses 非流式解析保留每一条输出消息的文本和工具调用；顶层 `output_text` 存在时不重复拼接。回归同时覆盖缺少摘要、空摘要和已有摘要。

宿主接入文档已同步独立 `ExternalAgentLoop`、必传执行适配器、显式原生 session 及不写 Framework checkpoint 的契约。页面浏览器测试允许通过 `PLAYWRIGHT_CHANNEL` 选择已安装浏览器，重挂载后等待初始化再交互。

本机 Playwright 默认 Chromium 缺失；安装下载完成后解压停滞，已停止该次安装。初次无界面系统 Chrome 的 iframe 指针点击未触发内部按钮；截图和 rect 诊断未见覆盖层或布局错位。有界面系统 Chrome 真实指针点击及键盘交互最终分别完整通过，日志为 `/tmp/framework-page-headed-pointer.log` 和 `/tmp/framework-page-keyboard-ultimate.log`。其他浏览器与平台未验证。

审查追加修复：官方 `CliExternalAgent` 的观察转交通道限制为 1024 条；慢消费导致溢出时明确失败并释放 CLI 调用，避免无界积压或静默丢事件。快 CLI／慢 sink 回归纳入最终 501 项验收。
